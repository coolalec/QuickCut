功能

不用學剪輯軟體，從開檔到輸出只要幾個步驟。

一鍵更新v1.2 新功能

有新版本時，在「關於」按「立即更新」就會自動下載、核對 SHA256、換上新版程式與 FFmpeg，再重新開啟；設定和開著的影片都會保留，失敗時會還原成原本的版本。

縮時與刪除區段v1.1 新功能

把冗長的一段加速成指定長度（例如 25 分鐘縮成 2 分鐘），或整段刪掉，其餘照常播放；在時間軸上直接拖曳調整，輸出長度即時顯示。

多段檔接成一條時間軸

一次拖進多個連續的分段檔，自動依檔名排序接起來，可以跨檔選取；之後也能再加檔案。

指定檔案大小

設定大小上限（例如上傳網站限制的 30 MB），依輸出長度自動計算流量；硬體編碼超出時會自動降流量重編。

顯示卡硬體加速

自動偵測並實際試編，優先使用 NVIDIA NVENC、AMD AMF、Intel QSV，沒有時改用 CPU。

有聲預覽、逐格檢視

內建 FFmpeg 解碼，H.265 也能直接播放；支援 ¼ ～ 2 倍速、逐格前後移動、目前畫面存成 PNG。

無損快速剪輯

不重新編碼、保留原始畫質與解析度，幾秒內完成；起點會對齊關鍵影格並顯示實際起點。也能搭配刪除區段使用。

直式影片與多種輸出

手機直拍影片維持原始比例；可選 H.264 / H.265、原始 / 1080p / 720p、保留或移除聲音。

快捷鍵

常用操作都能用鍵盤完成。

Space 或點畫面播放／暫停
← →上一格／下一格
Shift + ← →前後 1 秒
Ctrl + ← →前後 10 秒
I / O以目前畫面設起點／終點
[ / ]跳到起點／終點
S目前畫面存成圖片
M預覽聲音開／關
+ - \放大／縮小時間軸／顯示全部
T / D從目前位置新增縮時／刪除區段
Shift + 拖曳時間軸畫出新區段
Alt + 拖曳色帶整段移動區段
Ctrl + O / Ctrl + S開啟影片／輸出

安裝與使用

不需要安裝，解壓就能用。

  1. 下載：到 Releases 下載最新的 QuickCut-版本-win64.zip（標示 Pre-release 的是測試版）。
  2. 解壓：解壓到可寫入的資料夾，例如桌面或 D:\Tools，設定會存在程式旁邊。
  3. 執行：開啟 QuickCut\QuickCut.exe。程式沒有數位簽章，若出現「Windows 已保護您的電腦」，按「其他資訊」→「仍要執行」。
  4. 更新：有新版本時，程式的「關於」視窗會出現「立即更新」，按一下就會自動下載、驗證並重新開啟新版，設定會保留（v1.2 起；更舊的版本請再手動下載一次）。
  5. 驗證（選用）：想確認檔案確實由本專案的 GitHub Actions 建置，可用 GitHub CLI 執行 gh attestation verify QuickCut-版本-win64.zip --repo coolalec/QuickCut。

系統需求：Windows 10（1903 以後）或 Windows 11，64 位元；內建 .NET Framework 4.8 即可，不需另外安裝。
